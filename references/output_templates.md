# 输出模板

## 每日简报
```markdown
# A股市场情报简报｜YYYY-MM-DD
> 数据时间：...；公开数据有延迟；不构成投资建议。

## 一、今日核心事件
1. **标题**（来源 时间）——一句话影响判断。

## 二、海外市场与大宗
| 资产 | 最新 | 涨跌幅 |

## 三、国内政策与监管
- ...

## 四、资金与情绪
- 今日主力净流入前5 / 净流出前5
- 近3日主力净流入前5
- 北向/龙虎榜（如可用）

## 五、对A股的可能影响
- 利好：
- 利空：
- 待观察：

## 六、风险提示
- 数据延迟、口径差异、事件反转、拥挤交易。
```

## 个股画像
```markdown
# 个股情报｜名称（代码）
## 一、实时行情
## 二、近3日资金流
## 三、外资/北向（注明滞后）
## 四、前十大流通股东（季度）
## 五、社保/QFII线索
## 六、近期新闻
## 七、结论
- 机构：...
- 资金：...
- 事件：...
- 风险：...
```

## 候选池
```markdown
# A股策略筛选｜YYYY-MM-DD
| 代码 | 名称 | 现价 | 涨跌幅 | 3日净流入 | 今日净流入 | 评分 | 入选理由 |
## 风险与复核
- 资金流≠真实机构持仓
- 复核公告/减持/解禁/业绩/监管
- 候选池不是买入清单
```
